# SLP Education

A growing set of interactive educational resources for communication sciences and disorders.

| Lab | Folder | About |
|---|---|---|
| **Phonetics Lab** | [`phonetics-lab/`](phonetics-lab/) | The lab component of an undergraduate phonetics course: hear, see and build the sounds of English. |
| **Aphasia Lab** | [`aphasia-lab/`](aphasia-lab/) | The lab component of a graduate aphasia course: hands-on practice in clinical reasoning. |

Maintained by [Mengyang Qiu](https://mengyang.dev). Site built with the help of Claude (Anthropic).
