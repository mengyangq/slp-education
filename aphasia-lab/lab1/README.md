# Aphasia Lab: Reading the Scores

Interactive practice in interpreting aphasia assessment results, built for graduate students in speech-language pathology.

Eight fictional clients each come with results from the Comprehensive Aphasia Test (CAT): raw scores, whether each subtest is below the cut-off or within normal limits, the errors behind the scores, and a sample of the client's picture description. Learners can open any client. For each one they answer four questions (two on what the results show, a chart paragraph to complete and its closing sentence) and then read the model chart summary.

## Features

- Every wrong option has its own feedback, and a question can be retried until it is right.
- Findings collect under the questions as the learner confirms them.
- The model summaries follow one clinical chart format, so the eight clients can be compared.
- Progress stays in the learner's own browser; nothing is sent anywhere.
- Works on phones, tablets and desktops, and with the keyboard alone.

## Notes

No real CAT test items appear here. The error examples and the picture description scene are made up; the clients and their results are fictional, scored as in the CAT (Swinburn et al., 2004). The course version adds look-ups in the CAT's norm tables and runs in the course's learning management system.

Plain HTML, CSS and JavaScript, with no build step, libraries or tracking.
